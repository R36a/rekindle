# rekindle

> 本地优先的个人人脉管理器：**一句话记人，靠提醒维持联系**。

- **无自有服务端**：出站流量仅限你自己配置的 LLM 端点
- **可离线**：内置规则抽取，断网 / 没有 API key 也能用
- **不自动写入**：抽取结果先预填，你确认后才入库
- **可审计**：每次 LLM 调用（请求 / 响应 / token / 耗时）都留在本地

## 快速开始（骨架期）

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -e ".[dev]"
pytest                          # 冒烟测试
python -m rekindle --version
```

## 隐私

本工具不连接任何自有服务器。默认的「离线模式」不产生任何网络请求；开启 LLM 抽取后，
**你输入的原文会发送到你自己配置的端点**，不会经过本项目作者的服务器。
每次调用前的目标域名与将发送的文本都会展示，并记录在本地调用日志中。
