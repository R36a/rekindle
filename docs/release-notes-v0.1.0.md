## 亮点

- **默认完全离线**：运行时零网络请求，数据只存在本机
- **不自动写入**：抽取结果先预填，你点「确认入库」才写入
- **一句话 3 步**：输入 → 识别 → 确认；识别只预填，不会入库
- **公司按时间累积**：换公司不覆盖旧记录，能看到完整历史
- **可回退**：编辑前自动快照；恢复前再备份当前数据
- **同一套业务逻辑**：CLI / Tkinter GUI / FastAPI 接口共用 `app/` 用例层

## 工程

- 四层架构 + Protocol 端口；ruff + mypy --strict + 144 个测试
- 核心层覆盖率 94%，CI 设 90% 门禁
- `main` 分支通过 GitHub Actions 自动校验

## 已知限制

- LLM 抽取未接入（代码与测试保留，没有任何入口）
- 设置不持久化；消歧仅精确匹配；无全局热键 / 托盘
- 开发期数据库 schema 变更会重建库，升级前请先备份

## 快速开始

双击 `rekindle-v0.1.0-win64.exe`：

1. ① 输入一句话，按 `Ctrl+Enter` 识别
2. ② 核对并确认字段
3. ③ 搜索联系人（`Ctrl+F`）

数据默认在 `%USERPROFILE%\.rekindle\rekindle.db`。
