```
本地优先的人脉管理工具：一句话记人、离线抽取、确认后入库｜Python · SQLite · Pydantic · FastAPI · 144 tests
```

**Topics**

```
python, sqlite, pydantic, fastapi, tkinter, pytest, github-actions, desktop-app, offline-first, contacts
```

### 2. 创建 Release

仓库 → **Releases** → **Draft a new release**

| 字段 | 填什么 |
|---|---|
| Choose a tag | `v0.1.0` → Create new tag on publish |
| Release title | `rekindle v0.1.0` |
| 附件 | `dist\rekindle-v0.1.0-win64.exe` |
| 说明 | 复制 `docs/release-notes-v0.1.0.md` 全文 |
| Pre-release | 不勾 |

### 3. Pin 仓库

个人主页 → Customize your pins → 勾选 `rekindle`。
